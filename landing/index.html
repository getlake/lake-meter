THREE MOMENTS

Before, during, and after
every run.

01

Plan: a model per step

When Claude writes a plan, lake-meter rates each step 1 to 5, picks the cheapest model that should handle it, and adds a token range for each step. It shows up inside Claude Code's own plan dialog.

Two subagents, pinned to Haiku and Sonnet, make the advice one delegation away (skip them with --no-agents).

02

Run: a cap that asks

Set a budget per run in dollars, tokens, or a share of your 5-hour window. When a run reaches it, the next tool call becomes a permission prompt. Yes adds headroom. No stops Claude right there. Unattended runs end the turn instead.

Adjust anytime with /meter cap 10.

03

After: a measured receipt

When Claude stops, you get the run's real token count and its list-price cost, split by model and subagents. Your history stays in a local file for npx lake-meter report.

Plus a live meter in the statusline.
